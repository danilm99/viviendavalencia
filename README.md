# Vivienda en València

Sitio estático con dos páginas:

- `index.html` — informe sobre el parque de viviendas de València (precios, rentas, hogares, propietarios, gasto público, explorador de relaciones).
- `pisos-turisticos-valencia.html` — mapa de todos los pisos turísticos de la ciudad con ruta GPS y datos por barrio.

Se genera desde `src/` del proyecto local (`build_page.py` y `vivienda/build_report.py`). Publicado con GitHub Pages.
