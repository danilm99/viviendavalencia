# Guía de traducción castellano → valenciano (viviendavalencia.info)

Variedad: valenciano normativo (AVL, Diccionari normatiu valencià), registro periodístico divulgativo, como À Punt o la web de la Generalitat. Formas valencianas: este/esta/estos/estes, eixe, eixir, tindre/vindre, servici, mitjà/mitjana, prop de, ací, cap de setmana. Demostrativos y morfología verbal valencianos (preveu, ofereix → oferix, servix, patix; incoativos en -ix/-ixen), "nosaltres", "anys", "huit".

Glosario fijo:
- vivienda → habitatge (pl. habitatges); vivienda pública → habitatge públic; vivienda social → habitatge social; vivienda vacía → habitatge buit; vivienda turística (VUT) → habitatge turístic
- piso → pis (pl. pisos); piso turístico → pis turístic; pisos turísticos → pisos turístics
- alquiler → lloguer; alquilar → llogar; inquilino → llogater/llogatera; casero/arrendador → arrendador; propietario → propietari
- precio → preu; compra/compraventa → compra/compravenda; hipoteca → hipoteca; desahucio → desnonament; lanzamiento (judicial) → llançament
- renta → renda; salario → salari; sueldo → sou; hogar → llar; hogares → llars; padrón → padró; empadronado → empadronat
- anuncio → anunci; anfitrión → amfitrió; registro → registre; licencia → llicència; fianza → fiança
- gran tenedor → gran tenidor; zona tensionada → zona tensionada; barrio → barri; distrito → districte
- Ayuntamiento → Ajuntament; Generalitat → Generalitat; Consell → Consell; Ministerio → Ministeri; Tribunal Constitucional → Tribunal Constitucional
- dato/datos → dada/dades; fuente → font; cifra → xifra; gráfico → gràfic; ficha → fitxa; estimación propia → estimació pròpia; cálculo propio → càlcul propi
- Estadística oficial → Estadística oficial; Registro administrativo → Registre administratiu; Estudio → Estudi; Anuncios → Anuncis; Fuente institucional → Font institucional; Prensa → Premsa
- Ver como tabla → Mostra com a taula; Ocultar tabla → Amaga la taula; Descargar datos (CSV) → Descarrega les dades (CSV); Fuente y método → Font i mètode
- media → mitjana; mediana → mediana; tasa → taxa; índice → índex; trimestre → trimestre; anual → anual
- Mapa → Mapa; Datos (pestaña) → Dades; Informe → Informe
- Nombres propios sin traducir: València (siempre con acento grave), Ciutat Vella, l'Eixample, Russafa, Benimaclet, nombres oficiales de barrios y distritos (ya están en valenciano), nombres de empresas, de leyes extranjeras (Mietendeckel, encadrement des loyers…), siglas (INE, AEAT, CGPJ, UPV, UV, EVha, AUMSA, IBI, IRPF, SEPES, VUT, CATAV…). Las siglas castellanas oficiales se mantienen (INE, CGPJ, IBI).
- Nombres de ciudades: Viena, Berlín → Berlín, París → París, Ámsterdam → Amsterdam, Copenhague → Copenhaguen, Nueva York → Nova York, Singapur → Singapur, Irlanda → Irlanda, Países Bajos → Països Baixos, Cataluña → Catalunya, Comunitat Valenciana → Comunitat Valenciana, España → Espanya.
- Números: se conservan tal cual (los marcadores {0}, {1}… sustituyen a números).

Reglas técnicas (obligatorias):
1. Cada entrada tiene "k" (texto original, puede contener HTML) y "kind" ("html" o "text").
2. Conserva exactamente todos los marcadores {0}, {1}, {2}…: los mismos y cada uno una sola vez, aunque puedes cambiar su orden si la frase lo pide.
3. Conserva exactamente todas las etiquetas HTML y sus atributos (<b>, <a href="…" target="_blank" rel="noopener">, <span class="…">, <small>, <br>…), en el mismo número. Solo traduces el texto visible. No añadas ni quites etiquetas.
4. Conserva entidades como &nbsp; y signos como €, %, →, ·, –.
5. Si el texto es un nombre propio, una sigla o ya está en valenciano o en otro idioma (inglés, alemán…), devuélvelo igual.
6. Espacios: no añadas espacios al principio ni al final.
7. Estilo: claro, natural, sin calcos del castellano. Mantén el tono neutro y riguroso del original.
